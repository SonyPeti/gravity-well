# Gravity Well

> *Everything you destroy becomes part of your defense.*

A neon space idle-defense game for phones. You are a small planet under attack. Destroyed enemies get pulled into orbit and fight for you; every 3 waves you draft a mutation that bends the rules.

**Play:** https://sonypeti.github.io/gravity-well/ (on a phone: open it, then "Add to Home screen" to install it as an app)

## Features
- Capture enemies as orbiting moons: rock, ice, lava, drone, void and golden moons, each with its own effect
- Gravity Pulse: tap the planet to blast enemies back and fling your moons outward
- 20 mutations across 4 rarities, drafted every 3 waves
- Bosses every 10 waves: the World Eater and the Mothership
- Observatory: permanent upgrades and 6 unlockable planet skins, each with a perk and a drawback
- Supernova prestige: endless galaxies, each with a new enemy and twist, and a Constellation tree of new mechanics
- Daily Challenge with three seeded twists and fair-play rules; elite enemies with traits; three rotating bosses
- First-run coach hints, save codes for backup, auto graphics quality
- Home base hub, Bestiary with live enemy stats, daily missions and 28 achievements
- Combos, boss health bars, wave banners, slow-motion boss kills, phone vibration
- Offline earnings, sound and music, works offline once installed

## Run locally
```
node server.js
```
Then open http://localhost:8080 (or the printed address on your phone, same Wi-Fi).

## Project layout
| Path | What |
|---|---|
| `index.html`, `style.css` | Page and UI |
| `game.js` | Game logic and rendering |
| `audio.js` | Sound engine and music |
| `ads.js` | Rewarded-ad hook (stand-in until the app build uses AdMob) |
| `sw.js` | Offline cache, generated by `node tools/build-sw.js` |
| `assets/` | Sprites, icons, sounds, music |
| `art/source/` | Original art the sprites were cut from |
| `tools/` | Sprite cutter, audio builder, service worker builder |
| `GAME_DESIGN.md` | Full game design |

## Publishing an update
```
node tools/build-sw.js
git add -A && git commit -m "Update" && git push
```
GitHub Pages redeploys in about a minute; players get the new version the next time they open the game on the menu.
